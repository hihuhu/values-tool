# 价值观梳理工具

> 焦虑的反面是具体。这个工具帮你把「我到底在意什么」变成一张看得见、排得清的清单。

一个**单文件网页应用**：打开网页，三步把模糊的自我期待梳理成具体的结果。无需注册、无需安装、断网可用，你填的所有内容只存在自己的浏览器里。

**在线使用：<https://hihuhu.github.io/values-tool/>**

## 出自这本书

本工具实现的方法，出自 **《焦虑的反面是具体》** 一书中「梳理你的价值」的练习：

| | |
|---|---|
| 书名 | 焦虑的反面是具体 |
| 作者 | 【澳大利亚】朱迪·洛因格 |
| 译者 | 徐培培 |
| 出版社 | 山东画报出版社 · 果麦文化 |
| 出版时间 | 2024 年 4 月 |

书里的思路是：焦虑往往来自模糊——「我总觉得哪里不对，但说不清」。而破解模糊的办法是具体：先把「我在意的价值」逐条摊开，再给每条打分，**差距最大的那一项，就是最该行动的地方**。纸质练习需要手抄两张表、人工搬运和计算，这个工具把整段流程搬进了网页。

## 三步流程

**① 题库勾选**
内置 154 条价值词（每条带一句释义），按 A—C / D—H / J—L / M—R / S—Z 分组。逐条选三档之一：**非常重要 / 一般重要 / 完全不重要**。支持搜索、只看未选、键盘操作，也可以随时添加、编辑、删除你自己的条目。

**② 核心价值打分**
把第一步标为「非常重要」的条目导入第二步（建议 12–15 条），对每条分别打两个分：

- **重要性**（0–5）：它对你有多重要
- **一致性**（0–5）：你现在的生活做得有多一致

工具自动计算**差距 = 重要性 − 一致性**，≥ 2 标红（重要但没做到，是最该行动的地方），≤ 0 标绿，并给出从高到低的差距排行。

**③ 结果与导出**
一页看全：勾选概况、完整打分表、差距排行、差距最大的前三项行动建议。可导出 **Markdown / TXT / JSON**、一键复制全文、打印或存 PDF（打印时自动隐藏按钮只留内容）。导出的 JSON 可再次导入，用于换设备续填。

## 隐私说明

- **没有服务器，没有账号，没有任何网络请求**——整个工具就是一个 HTML 文件。
- 你的答案只写入**你自己浏览器的 localStorage**，每步操作即时保存，刷新、关机、重启都不丢；别人（包括仓库维护者）无法看到。
- 换设备或换浏览器：用「导出答案 JSON」备份，在新设备「导入」即可。
- 本仓库是公开的（GitHub Pages 免费版的要求），公开的只是**工具代码和题库**，不是你填的答案。

## 本地使用

方式一：直接双击打开 `index.html`——完全离线可用，适合填表和打印。

方式二：访问在线版 <https://hihuhu.github.io/values-tool/>，手机（375px 起）和电脑都能完整使用。

> 注意：本地文件打开的答案和在线网址的答案存在两个不同的本地"仓库"里，互不相通；迁移前请先导出 JSON。

## 项目结构

```
values-tool/
├─ index.html            # 工具本体（唯一入口，全部逻辑内联，断网可用）
├─ index.template.html   # 开发模板（构建时题库占位符在这里）
├─ values-bank.json      # 题库源数据（154 条，改题只改这个文件）
├─ tools/
│  ├─ build.mjs          # 构建脚本：模板 + 题库 → 打包出 index.html
│  └─ verify-*.mjs       # 自动化验证脚本（Puppeteer 全流程回归）
└─ README.md
```

## 开发

改题库：编辑 `values-bank.json`，然后

```bash
node tools/build.mjs
```

即可重新生成 `index.html`（题库已内联其中）。

自动化验证：

```bash
node tools/verify-v5.mjs    # 基础功能回归
node tools/verify-m5.mjs    # 结果页与导出全量测试
```

## 技术说明

- **单文件**：原生 HTML / CSS / JS，零框架、零依赖、零 CDN、零网络请求——一个文件就是全部，断网可用，也不会因第三方库升级而损坏。
- **数据**：单一 `state` 对象 + 即时写入 localStorage；步骤切换只换视图不清数据，可随时来回改。
- **兼容**：Chrome / Edge / Safari / Firefox 近两年版本；移动端 375px 全功能适配。
- **无侵入**：不收集任何数据，没有统计、没有埋点、没有 Cookie。
